NUSANTARA HANTARAN — WEBSITE

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka index.html menggunakan browser (Chrome/Edge/Firefox).
3. Koneksi internet diperlukan untuk Google Fonts dan foto contoh dari Unsplash.

WAJIB DISESUAIKAN SEBELUM DIPUBLIKASIKAN
1. Buka script.js.
2. Ganti BUSINESS_WHATSAPP = "628xxxxxxxxxx" dengan nomor WhatsApp usaha, contoh format: "6281234567890".
3. Ganti BUSINESS_ADDRESS dengan alamat lengkap usaha.
4. Ganti foto contoh pada katalog/hero dengan foto produk dan foto usaha milik sendiri.
5. Ubah nama produk dan harga contoh pada array `products` di script.js.

FITUR
- Navigasi responsif untuk HP dan desktop.
- Filter kategori katalog.
- Tombol tanya produk melalui WhatsApp.
- Formulir konsultasi yang menyusun pesan WhatsApp.
- Ulasan pelanggan dengan rating; ulasan tersimpan pada browser/perangkat yang mengirimkannya (localStorage), belum tersinkron antar-pengunjung.

HOSTING
Hosting belum dilakukan. Website dapat diunggah ke layanan hosting statis seperti GitHub Pages, Netlify, atau layanan hosting pilihan Anda. Untuk ulasan yang bisa dilihat semua pengunjung, diperlukan backend/database; versi ini menyimpan ulasan secara lokal di browser.


CATATAN FOTO REFERENSI
Foto contoh hantaran diambil dari hasil pencarian gambar dan ditautkan ke situs sumbernya. Foto ini berfungsi sebagai inspirasi/placeholder. Sebelum website dipakai untuk promosi komersial, pastikan izin penggunaan atau lisensi dari pemilik foto sudah sesuai. Sebaiknya ganti dengan foto hasil karya/produk sendiri atau foto stok berlisensi.
